## 🚀 GitHub Pages-এ আপনার ওয়েব পেজ যেভাবে আপডেট করবেন

### উপায় ১: একক ফাইল দিয়ে ১ মিনিটে আপডেট (প্রস্তাবিত — কোনো আনজিপের প্রয়োজন নেই)
1. [GitHub.com](https://github.com)-এ গিয়ে আপনার রিপোজিটরিতে (যেমন `joma-khoroch` বা `_deposite_expence`) প্রবেশ করুন।
2. সেখানে থাকা `index.html` ফাইলটিতে ক্লিক করুন।
3. ডানদিকের **পেন্সিল (Edit)** আইকনে ক্লিক করুন।
4. আমাদের প্রোজেক্টের `web/index_standalone.html` ফাইলের সম্পূর্ণ কোড কপি করে পূর্বের কোডের জায়গায় রিপ্লেস/পেস্ট করে দিন।
5. নিচে সবুজ **"Commit changes"** বাটনে ক্লিক করুন।
6. ১-২ মিনিট পর আপনার লিংকে রিলোড দিলেই নতুন "হিসাব সেভ সফল" পপ-আপ সহ সব নতুন ফিচার লাইভ দেখতে পাবেন!

---

### উপায় ২: জিপ ফাইল ডাউনলোড ও এক্সট্র্যাক্ট করে আপডেট
1. প্রোজেক্টের রুট থেকে **`joma_khoroch_web.zip`** ফাইলটি ডাউনলোড করে আনজিপ/Extract করুন।
2. GitHub রিপোজিটরিতে গিয়ে **"Add file" ➔ "Upload files"**-এ যান।
3. আনজিপ করা ফাইলগুলো (`index.html`, `style.css`, `app.js`, `manifest.json`) আপলোড করে **Commit changes** করে দিন।
4. কিছুক্ষণের মধ্যেই আপনার GitHub Pages স্বয়ংক্রিয়ভাবে আপডেট হয়ে যাবে।
