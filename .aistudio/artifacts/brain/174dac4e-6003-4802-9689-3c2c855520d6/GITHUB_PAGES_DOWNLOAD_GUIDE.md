এই ডকুমেন্টে আপনি পাবেন আপনার **জমা-খরচ** অ্যাপটির সম্পূর্ণ ওয়েব সংস্করণ যা দিয়ে আপনি **GitHub Pages**-এ সম্পূর্ণ ফ্রি-তে একটি লাইভ ওয়েবসাইট চালাতে পারবেন। এতে **মাসিক বাজেট সতর্কতা**, **UPI অনলাইন পেমেন্ট**, **Date-to-Date রিপোর্ট**, **স্বয়ংক্রিয় প্রতি মাসের হিসাব (Recurring)** এবং **অফলাইন ব্যাকআপ** সব যুক্ত আছে।

## 📍 ওয়েব ফাইলগুলো কোথায় আছে?

AI Studio-এর বাঁদিকের ফাইল এক্সপ্লোরার (File Explorer)-এ ফাইলগুলো সরাসরি সাজানো রয়েছে:

```text
📁 মূল প্রজেক্ট
│
├── 📦 joma_khoroch_web.zip          <-- সম্পূর্ণ ওয়েব অ্যাপের জিপ ফাইল (ডাউনলোড ও আনজিপ করার জন্য)
│
└── 📁 web/                          <-- রেডি ওয়েব ফাইলগুলোর ফোল্ডার
    ├── 📄 index.html                (ওয়েব পেজের মূল ফাইল)
    ├── 📄 index_standalone.html     (একক ফাইল — সব কোড একসাথে যুক্ত)
    ├── 🎨 style.css                 (এমারেল্ড গ্রিন রেসপন্সিভ ডিজাইন ও ডার্ক মোড)
    ├── ⚡ app.js                    (বাজেট অ্যালার্ট, UPI অনলাইন ও লোকাল ডেটাবেজ)
    ├── 📱 manifest.json             (মোবাইলে PWA হিসেবে ইনস্টল করার কনফিগারেশন)
    └── 📖 README.md                 (বিস্তারিত বিবরণ)
```

## 🚀 GitHub Pages-এ ওয়েবসাইট চালু করার ৩টি সহজ উপায়

### উপায় ১: সবচেয়ে সহজ (একক ফাইল - No Extract / কোনো ঝামেলা নেই)
আপনাকে কোনো ফাইল এক্সট্র্যাক্ট বা আনজিপ করতেই হবে না! শুধুমাত্র `index_standalone.html` ফাইলটি GitHub-এ দিলেই কাজ শেষ:

1. [GitHub.com](https://github.com)-এ গিয়ে **New Repository** তৈরি করুন (যেমন: `joma-khoroch`)।
2. **Public** নির্বাচন করে **Create repository**-তে ক্লিক করুন।
3. **"Add file"** ➔ **"Create new file"**-এ ক্লিক করুন।
4. ফাইলের নাম দিন: `index.html`
5. `web/index_standalone.html` ফাইলটির সমস্ত কোড কপি করে পেস্ট করে দিন।
6. নিচে সবুজ **"Commit changes"** বাটনে ক্লিক করুন।
7. রিপোজিটরির **Settings** ➔ **Pages**-এ যান।
8. **Branch** ড্রপডাউনে **`main`** সিলেক্ট করে **Save** বাটনে চাপুন।
9. ২ মিনিট পর আপনার ওয়েবসাইট লাইভ হয়ে যাবে:
   👉 `https://ajoy720.github.io/joma-khoroch/`

---

### উপায় ২: জিপ ফাইল (ZIP) ডাউনলোড ও এক্সট্র্যাক্ট করে আপলোড

1. আপনার প্রোজেক্টের রুট থেকে `joma_khoroch_web.zip` ফাইলটি ডাউনলোড করে আপনার কম্পিউটারে বা মোবাইলে Extract (Unzip) করুন।
2. আনজিপ করলে আপনি ৫টি ফাইল পাবেন:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `README.md`
3. GitHub রিপোজিটরিতে গিয়ে **"Add file"** ➔ **"Upload files"** নির্বাচন করুন।
4. আনজিপ করা ফাইলগুলো টেনে এনে ছেড়ে দিন (Drag and Drop) এবং **Commit changes**-এ ক্লিক করুন।
5. **Settings** ➔ **Pages** ➔ Branch: **`main`** সেভ করলেই ওয়েবসাইট চালু!

### উপায় ৩: পূর্বের `_deposite_expence` রিপোজিটরিতে আপডেট

আপনার যদি আগে থেকেই GitHub Pages লিংক চালু থাকে:
1. GitHub-এ গিয়ে আপনার `_deposite_expence` রিপোজিটরিতে যান।
2. **"Add file"** ➔ **"Upload files"**-এ যান।
3. নতুন `index.html`, `style.css`, `app.js` আপলোড করে **Commit** দিন।
4. সাথে সাথে নতুন **মাসিক বাজেট সতর্কতা** ও **UPI অনলাইন** যুক্ত হয়ে যাবে।
